## 🌟 核心优势与功能特性

### 1. 🎨 UI 全面重构 & 6 种多彩轻主题
- **对标热门主流 APP 的高颜值排版**：全面优化页面间距、卡片倒角与视觉层次，带来更纯粹、通透的原生现代阅读体验。
- **支持大图、小图、无图三种浏览模式**：全方位满足沉浸图文、紧凑高密与纯文本极简省流的多样阅读偏好，大图沉浸、小图精致、无图极简，想怎么看就怎么看。
- **6 款多彩轻主题随心换**：小黄、小绿、小蓝、小紫、经典灰、猛男粉想用哪个用哪个，点按即切，全站即时生效。
- **个性化个人主页**：支持自定义主页背景图与动态头像穿透展示，徽章模块横向滑动浏览。

### 2. 👥 应用内多账号无感切换
- **一键热插拔切换**：支持存储多账号凭据，在个人中心或侧边栏一键秒切，无需繁琐的退出与重新登录。
- **多维度安全隔离**：不同账号间的会话凭证、独立草稿箱、未读角标与个性化配置严格隔离，彻底告别串号隐患。

### 3. 🏆 原生等级积分与升保级资产卡
- **升级必备神器**：个人中心原生集成 L 站等级积分站卡片，清晰呈现当前等级、升级所需项及各项达标差额，升保级心中有数。

### 4. 🛡️ 原生 DoH + ECH TLS 安全直连（免代理突破阻断）
- **真·加密直连**：基于原生二进制网络层，全面支持 **DoH (RFC 8484)** 与 **ECH (RFC 9460)** 加密 ClientHello，彻底隐藏 SNI 目标域名，国内网络直连访问不阻断。
- **预置多路优选节点**：内置国内三网优选直连节点（如 L 站专属优选节点等），支持多路端到端真实测速与毫秒级延迟展示。
- **高可用容灾与网络自愈**：主节点异常时秒级自动故障转移，并提供一键网络自愈与底层 DNS 兜底保护。
- **智能 VPN / 代理感知**：检测到系统开启 VPN 或代理软件时，自动平滑暂停 DoH 并直接走系统代理，免除分流冲突。

### 5. 🔒 核心会话长效稳定不掉盾
- **精准解耦凭据架构**：严格遵循 Cloudflare 验证指纹规范，将论坛账号会话（`_t`）与设备级过盾指纹凭证（`cf_clearance`）精准解耦置换，彻底攻克 `CSRF 403` 与频繁跳盾难题。
- **安全挑战无缝闭环**：偶发人机验证在独立安全弹层内无感闭环，并通过连续静默探测自动重放业务请求，日常刷帖告别 CF 盾死循环与转圈。

### 6. 🔔 本地推送通知与桌面未读角标
- **前台未读消息极速感知**：前台未读角标轮询与后台设置解耦，停留页面时 5～10 秒高敏轮询，时效性拉满。
- **高可靠多维保活**：支持「亮屏抢跑即刻拉取 + 退回桌面即时刷新 + 息屏硬件阶梯闹钟」，强力穿透各品牌国产系统（MIUI/HyperOS、HarmonyOS、MagicOS、ColorOS、OriginOS 等）的后台冻结。

### 7. ✍️ 全能创作发布与互动升级
- **支持发布新话题**：完整支持选择主/子分类、标签（Tags）、标题输入、正文撰写与附件上传。
- **所见即所得图文混排编辑**：评论与发帖支持所见即所得编辑器，支持 Markdown 语法快捷插入、原生图片插入及缩略图快速移除。
- **丰富互动操作**：贴内 Emoji 表情选择器、楼层链接复制、书签收藏/取消收藏、编辑、删除与举报等全套原生操作。

### 8. 📌 个性化定制与版块管理
- **分类自定义排序**：在“分类”页面长按卡片自由拖拽调整顺序，把常用的版块统统置顶在前，本地永久记忆且支持一键恢复默认。
- **关注版块双向同步**：自选关注版块与 L 站 Web 端双向实时同步，多端无缝协同。
- **话题 4 档通知级别**：支持单帖精细化设置「关注 / 跟踪 / 常规 / 免打扰（Muted）」，彻底屏蔽不想关注的话题动态。

### 9. 🚀 应用内流式无感更新
- **安全与流式体验**：原生流式下载进度实时展示，支持 SHA256 哈希完整性自动校验，下载完成一键无缝拉起系统安装器。

### 10. 💎 纯正原生开发与细节打磨
- **Kotlin + Jetpack Compose 全原生构建**：拒绝套壳，包体轻盈；全屏跟手侧滑返回动效，本地分类缓存预热实现冷启动秒开。
- **外观与主题**：完美适配浅色 / 深色 / 跟随系统三档外观，配合多彩轻主题自由搭配。
- **站长专属彩蛋**：定制站长 neo 专属方形头像展示，深度致敬 L 站社区。
- **全能安全登录**：支持账号密码 / 邮箱验证码登录、**2FA 两步验证（TOTP 动态口令与恢复码）**、L 站风控网页授权一键认证。
